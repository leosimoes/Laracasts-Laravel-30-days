# Day 1 - Hello, Laravel

## Web Development Ecosystem with PHP
The PHP ecosystem is broad:
* Web Servers: Apache, Nginx;
* Development Packages: XAMPP, WAMP, MAMP, Laragon;
* Frameworks and Tools: Laravel, CodeIgniter, Yii, CakePHP, Symfony;
* Dependency Manager: Composer;
* CMS (Content Management Systems): WordPress, Drupal, Joomla;
* E-commerce Platforms: Magento, OpenCart, PrestaShop, WooCommerce (WordPress plugin), 
Bagisto (based on Laravel);


## Project Configurations
The tools and their versions used in development were:
* PHP 8.4;
