# Laracast - 30 Days to Learn Laravel

## Project Execution
One way to run the project is:
1. Install **Laravel Heard**;
2. Go to the **Sites** section;
3. Click **Add** and point to the project directory;
4. Click the provided URL (http://laracasts-laravel-30-days.test/).
